MAC + WINDOWS. BUILT IN THE OPEN.
MIRACLE FOR MAC · DMG

Your download.
A little setup.

Miracle v0.3.0 is a free, open-source test build for Apple Silicon. It is locally signed, but isn’t notarized by Apple. macOS may block the first launch.

  1. Move Miracle to Applications.

    Open miracle.dmg and drag Miracle onto its Applications folder. Open Miracle from Applications after copying it.

  2. If macOS blocks it, review the app.

    After attempting to open Miracle, go to System Settings → Privacy & Security. If you trust this official download, choose Open Anyway for Miracle and confirm. This follows Apple’s opening instructions ↗.

  3. Select a file. Tap Shift.

    Miracle lives in your menu bar. Select a supported file in Finder, tap Shift, then choose a format. The converted copy saves beside the original.

Use only the official Miracle release you trust. If macOS reports malware or an altered app, stop and check the release or report the issue.
