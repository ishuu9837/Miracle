02 / MAC SETUP

One open.
Then one Shift.

  1. Open miracle.dmg and drag Miracle into Applications.
  2. Open Miracle from Applications. This test build is not Apple notarized. If macOS blocks it, first review the official release and then use System Settings → Privacy & Security → Open Anyway only if you trust the download. Follow Apple’s instructions.
  3. Complete the app’s setup and any macOS permission prompts needed for Finder integration.
  4. Select a supported file in Finder, tap Shift, and choose an available conversion. The new copy saves to the configured output location.
  5. Miracle stays in the menu bar. Use its menu to manage settings, recent jobs, or quit.

Check the Mac release notes for the Mac build’s actual scope. The Windows feature table below does not describe Mac coverage.

03 / WINDOWS SETUP

Unpack.
Open. Make magic.

  1. Choose x64 for Intel or AMD PCs. Choose ARM64 for Snapdragon devices or an ARM Windows VM. Find your processor under Settings → System → About.
  2. Extract the entire .7z to a local folder. Windows 11 24H2 or later supports Extract All for this package; an up-to-date 7-Zip is another option.
  3. Keep Miracle.exe, the Engines directory, and all companion files together. Do not run the app from inside the compressed archive.
  4. Open Miracle/Miracle.exe. If the Microsoft C++ runtime is missing, install the matching official Microsoft redistributable included in Prerequisites. That installer can request administrator approval; the app runs with ordinary user privileges.
  5. Wait for the engine check to finish. The logo intro leads into the colorful main window.
Unsigned preview. There is no verified publisher certificate yet. SmartScreen can warn and Smart App Control can block this build. Local Defender checks do not establish reputation or compatibility with enforced Smart App Control. We do not recommend disabling Windows protections.
04 / TWO WINDOWS FLOWS

Buttons, or
a little Shift.

Use the colorful buttons

  1. Click Add files or drop supported files into the app.
  2. Choose a colored output-format button.
  3. Choose an output folder, or keep Save beside the originals.
  4. Click Convert file. Use Show result when it completes.

Drag + Shift + slide · Windows 0.3.2

  1. Keep Miracle running. Closing its main window leaves it in the system tray.
  2. Begin dragging a supported file or selection from a File Explorer window. Keep holding the mouse button.
  3. Tap Shift once to open the colorful wheel.
  4. Tap Shift again for each next set: common conversion formats first, then common file tools. Sets contain up to six choices and wrap around.
  5. Slide onto a colored choice and release. A format starts conversion; a tool opens its settings first.

Esc cancels. Release outside a colored option to dismiss the drag wheel. Shift chords, long holds, and auto-repeat do not repeatedly open it. You can turn off the Explorer shortcut in the app. A non-drag wheel also provides a Next set button. The shortcut supports foreground File Explorer, not desktop selections or arbitrary drag sources in other applications.

Only options shared by the selected files appear. Originals are preserved, and existing outputs receive new names. You can cancel a running job; completed results stay and unfinished staged work is removed during normal cancellation.

06 / HONEST LIMITS

The useful details.

  • Windows does not export genuine Apple Pages files. Use DOCX for exchange with Pages; macOS RTFD bundles and text clippings are not Windows inputs.
  • PDF → JPG/PNG exports every page at 300 DPI, subject to resource limits. PDF → PPTX uses page images. PDF → XLSX exports extracted page text, not reconstructed tables.
  • Scanned PDFs need OCR, which this preview does not include. Native document routes reflow text; complex layouts can change.
  • Image tools use the first image frame. GIF → video uses FFmpeg, but a silent GIF cannot produce a meaningful MP3.
  • Compression can sometimes create a larger result. Check redaction, layout, timing, transparency, and metadata before sharing outputs.
  • Archive extraction rejects unsafe paths, links, encrypted entries, and duplicate paths, with entry and expansion limits. GZIP packaging uses a TAR container.

Read the release verification evidence for tested scope. x64 checks here run under ARM emulation in a Windows VM; native Intel/AMD hardware and clean-machine reputation checks remain separate work.

07 / WHEN SOMETHING NEEDS A NUDGE

Keep the flow.

The Windows wheel does not open
Confirm Miracle is running, the engine check has finished, and the Explorer shortcut is enabled. Start a drag from a File Explorer window, hold the mouse, and tap Shift briefly. Close an existing wheel with Esc and try again. Other apps may also use Shift; colorful in-app buttons are always available.
A format is missing
Try one supported file at a time. Mixed selections show only common outputs. Verify the app’s engine status and retain its bundled Engines folder. Input corruption, missing audio streams, and unavailable encoders can limit a route.
The app stays running after closing
This is the tray/menu-bar behavior. Open the icon’s menu and choose Quit to stop Miracle and its shortcut.
A conversion fails
Check the destination, free disk space, and source file with a small sample. Keep outputs on a local writable drive. Include the OS, app version, input extension, output format, and a nonsensitive error message when reporting a bug.

Report a bug on GitHub ↗. Issues are public: never attach private files, credentials, or unredacted personal paths. See the Privacy Policy for local history and data practices.
